# Design System: Pace

> **TARGET system — not yet shipped.** Source: `context/design/redesign-spec.md` (direction A · Тетрадь, approved 2026-11-01). Regenerated from the shipped code at the end of the overhaul (plan Task 8.4).
>
> Until then this file describes what the overhaul builds, not what `apps/app` renders today. The previous description of the shipped (incumbent) system is in git history at commit `e956e99`. Where this file and the spec disagree, the spec wins; where the spec names a direction-B detail (station rings, the metro line, "Pace green", pill tags with dots), direction A replaces it as written here.

## Overview

**Creative North Star: "The Squared Notebook"**

Pace is a school notebook used as a tool: cool squared paper, ballpoint-blue ink and a red margin rule. The ink does every interactive job (the one primary action, links, the current selection, the focus ring, done); the red margin is status only (the now-line on Day, overdue, Urgent, destructive). Everything at rest is neutral paper and graphite text, so the content (task titles, times, the day's shape) is the brightest thing on the screen.

The app works in Operate mode on every surface: the person is in the middle of a task, so scanability, consistency and platform expectations outrank expression. The world contributes type rhythm, palette, density and one signature detail; the shell, navigation and controls are the platform's (Material affordances on Android, web semantics on the web, Apple-productivity-grade craft on both). A screen is one ground with grouped list sections on it; elevation is only for things that float. Time is drawn as time: one formatter, tabular figures, proportional spans wherever a screen shows a day.

The signature lives on Day: the timeline sits on a faint 4-pt dot grid (only behind the timeline), crossed by a red now-line; the running activity reads as an ink line with a red mark at its expected length. Both themes, both scripts (Latin and Cyrillic) and the worst case (long Russian names, 1 284 tasks, font scale 1.6) are part of the design, not tests after it.

**Key Characteristics:**
- One cool accent (ink blue) for every interactive job; red is status, never decoration.
- One surface with grouped lists; separators only between rows of a group, inset to the text.
- Inter only, thirteen fixed type roles, tabular figures for every number.
- A 4-pt spacing scale and seven radii; nothing off-scale exists.
- Depth by tonal step; shadows only on floating layers in light, a hairline in dark.
- Every press answers within a frame; every overlay leaves the way it came; nothing exceeds 300 ms.

## Colors

Cool paper neutrals carry the screen; one ink-blue accent and one red margin colour do the talking; a twelve-hue family (plus slate) carries categories and projects as pen colours.

Every role exists in a light (`light-…`) and a dark (`dark-…`) token; components reference the light token and switch to the `dark-` sibling of the same role in dark theme. The dark theme is ink-night, not a grey inversion.

### Primary
- **Ballpoint Ink** (light #2E4AD6 / dark #97A9FF): the accent. The one filled primary button per view, the switch track when on, the selected calendar day, the current-nav leading bar, the selected-row bar, the check circle at the moment of checking. Its text form **Ink Text** (#2E4AD6 / #ACBAFF) is for links, plain text buttons (Undo, «Вернуть»), selected chip labels, and `status-success` (done is ink, as in a notebook). **Ink Pressed** (#2640BC / #8498F7) is the pressed primary button. **On-Ink** (#FFFFFF / #0B0D14) is text on an ink fill. **Ink Wash** (`accent-quiet`) is the selected-chip fill and the one-time highlight of a row an assistant proposal just created.
- **Focus Ink** (#2E4AD6 / #ACBAFF): the focus ring, 2 px with a 2 px offset, on every focusable element.
- **Selection Ink** (`selection`): web text selection and the selected-row fill, always together with a non-colour marker (the leading 3 px bar or a checkmark).

### Secondary
- **Red Margin** (light #C3352B / dark #FF8274, `status-danger`): the now-line on Day, overdue and late times, the Urgent word, destructive actions and errors, the unsorted-Inbox count badge. Its wash (`status-danger-quiet`) fills the destructive button and danger notices.

### Tertiary
- **Burnt Orange** (#B04A0C / #FFA870, `status-warn`): "past expected" only: «Всё ещё занимаетесь?», the running line past its expected length. Wash `status-warn-quiet` for notices.
- **Question Ochre** (#795300 / #F2C275, `status-question`): assistant questions and the «?» mark on a field the model only guessed.
- **Logo Lime** (#5E8C00 on light / #C8F03C on dark, `logo`): the lime chevron of the Pace mark. Used only by the logo, the favicon and the app icon.
- **Hue family** (`hue-<name>-stroke`, `hue-<name>-ink`, plus a `tint` at 12 % light / 18 % dark in the sidecar): red, orange, amber, yellow, lime, green, teal, cyan, blue, indigo, violet, pink, slate. `stroke` draws lines, dots and chart marks (≥ 3:1 on `bg-app` in both themes); `ink` is text on its own tint (≥ 5.6:1); `tint` is the tag fill. Activity categories: work blue · study violet · task green · food orange · commute yellow · hygiene cyan · rest teal · chores amber · social pink · sport red · sleep indigo · other slate. Projects keep their ten stored names (`coral` maps to red).

### Neutral
- **Cool Paper** (#F4F5F9 / #0D0F15, `bg-app`): the screen ground and the grouped-list background.
- **Sheet White** (#FFFFFF / #161922, `bg-cell`): grouped-list cells, the composer, the running card, the tab bar.
- **Lifted Sheet** (#FFFFFF / #1F2333, `bg-elevated`): sheets, dialogs, popovers, toasts, tooltips.
- **Margin Paper** (#ECEEF4 / #0A0C11, `bg-sidebar`): the desktop sidebar, a second neutral layer.
- **Inset Paper** (#F8F9FC / #12141B, `bg-inset`): fields inside cells, token boxes.
- **Graphite** (#12141C / #ECEEF4, `label-primary`): titles, row titles, values, the live elapsed time.
- **Pencil** (#474C60 / #C3C7D5, `label-secondary`): meta lines, section headers, secondary values, default icon colour, the Low-importance title.
- **Faded Pencil** (#646A80 / #A0A5B9, `label-tertiary`): captions, timestamps, placeholders, at ≥ 13 px and weight ≥ 400 only.
- **Erased** (#B4B8C7 / #4A4F63, `label-quaternary`): never text. Disabled glyphs, the sheet handle, decorative strokes.
- **Ruled Edge** (#878CA0 / #767C93, `outline`): the boundary of a control that has no fill to mark it (fields at rest, the switch track off, the unchecked check circle, the dashed draft border); ≥ 3:1 on cell and app.
- **State fills** (`fill-1` hover, `fill-2` pressed and neutral controls, `fill-3` selected-neutral and the Android ripple, `fill-4` tracks): ink-tinted alpha, so they compose on any layer.
- **Rules** (`separator`, `separator-opaque` where alpha would stack): between rows of a group, inset to the text start; the sidebar edge; a scroll-edge hairline under a header.
- **Dot Grid** (`grid`): the notebook dots behind Day's timeline, nowhere else.
- **Scrim** (`scrim`): behind sheets and dialogs.

### Named Rules
**The One Ink Rule.** Ink blue is the only interactive colour, and a screen at rest shows at most one filled ink element. On desktop the sidebar's New task button is that element, so screens keep their own actions tonal until something is ready to commit.

**The Red Margin Rule.** Red marks status: the now-line, overdue, Urgent, destructive, errors. It is never decoration, never a brand flourish, never a category.

**The Pen Colour Rule.** A category is a 1 px line (or a small dot in a value, a chip or a legend) in its hue's `stroke`, with its name in `label-*`. A project is a tag: hue `tint` fill and hue `ink` text, `rounded.sm`. «В работе» / In progress is a violet tag, because blue belongs to the ink. Importance has no colour of its own: Urgent is a red word, Priority a bold word in `label-primary` (600), Low shows no word but draws the title in `label-secondary`, Normal shows nothing.

**The Logo Lime Rule.** Lime belongs to the Pace mark, favicon and app icon. It never appears as an interface colour.

## Typography

**Display Font:** Inter (with system-ui, sans-serif)
**Body Font:** Inter
**Label/Mono Font:** Inter with tabular figures (`tnum`); no second family

**Character:** One grotesque for every job, Latin and Cyrillic, set at Material/HIG body sizes with a gentle ≈ 1.15 ratio. Hierarchy comes from size, weight (400, 500, 600, 700) and the four label colours, never from a second face or decoration.

Frontmatter sizes are the phone values; desktop steps every role down by one or two pixels (desktop values in the sidecar). Line heights are Russian-safe: ≥ 1.25 for titles, ≥ 1.35 for body and meta. On Android sizes are `sp` with font scaling on; chrome (tab labels, badges, time-bar buttons) caps at a 1.6 multiplier, content does not.

### Hierarchy
- **Large Title** (700, 32/38 phone, 28/34 desktop, −0.022em): the top-level screen title (Now, Day, Week, Inbox, Projects, Insights, History, Settings, More), at the same height on every destination.
- **Title 1** (600, 24/30, 22/28 desktop): the title of a pushed screen (task, project, preset).
- **Title 2** (600, 20/26, 18/24 desktop): sheet, dialog and detail-pane titles.
- **Headline** (600, 17/22, 15/20 desktop): group headers that are headings, emphasised row titles, the period label, empty-state titles.
- **Body** (400, 16/22, 15/21 desktop): row titles, paragraphs, field text (16 on phone web so iOS never zooms). Task-row titles use 500.
- **Callout** (400, 15/20, 14/19 desktop): button labels (at 600), secondary paragraphs, sheet body copy, trailing values, subtitles under a large title.
- **Subhead** (500, 14/19, 13/18 desktop): section headers of grouped lists (sentence case, `label-secondary`), chip and segment labels.
- **Footnote** (400, 13/18, 12/17 desktop): meta lines under row titles, field labels and messages, tooltips, key hints.
- **Caption** (500, 12/16, +0.01em): tags, tab labels, chart labels, time-bar button labels.
- **Caption 2** (600, 11/14, +0.02em): badges only. Nothing functional goes below 11 px.
- **Numeric Live** (600, 22/26, 20/24 desktop, tnum): the running activity's elapsed time, the largest live number on Now.
- **Numeric Value** (500, 16/22, 15/21 desktop, tnum): durations, times and counts in rows.
- **Numeric Stat** (600, 28/32, 24/28 desktop, tnum): Insights tile values.

### Named Rules
**The No Kicker Rule.** Nothing sits above a title: no eyebrow, no kicker, no small-caps date. The date is a subtitle under the large title (Now, Day) or lives in the period control (Week, History, Insights).

**The Tabular Time Rule.** Every duration, clock and count uses a numeric role (tabular figures built in) and one core formatter: Russian gets a non-breaking space before units («2 ч 05 мин», «1 284»), a decimal comma, and hours roll into days past 48 h.

**The One Section Header Rule.** A section header is `subhead`, sentence case, `label-secondary`, 24 px above and 8 px below, inset to line up with cell text, announced as a heading of its level.

## Layout

A 4-pt scale (0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64) is the only spacing that exists; the Tailwind scales are replaced by the token scales and arbitrary values are a lint error. Sizes are px/dp with NativeWind `inlineRem` at 16, so Android and the web measure the same.

**Shell.** One shell, three regions: navigation · content · inspector. `compact` < 600 px (phone: a Material navigation bar, pushed screens, sheets); `medium` 600–1023 (a navigation rail 80 wide plus content; the inspector opens as a sheet; rotation unlocked); `expanded` ≥ 1024 (sidebar 248 + content + inspector 400, min 360, max 480). The inspector exists only on screens with a selection (Now, Day, Week, Inbox) and collapses when nothing is selected.

**Page template.** One `ScreenHeader` per screen type (destination: large title; pushed: back + inline title), then content in a column of 720 (list screens) or 960 (Day, Insights) at most; on desktop the window scrolls, not the column. Screen gutter 16 phone, 32 desktop content, 24 in a pane. Grouped-list rows pad 16 × 12 (16 × 10 desktop), gap 12 between leading control and text, minimum height 52 phone / 44 desktop; 8 between groups, 24 (28 desktop) between sections; header block 8 below the top inset (28 desktop) and 12 (16) above content; sheets pad 20 (24).

**Density.** Calm-dense: two-line task rows (66 or 88 dp, never data-dependent), no decorative panels. Text yields, controls do not: every text slot declares truncate, truncate-middle, wrap, clamp(n) or count; UI strings wrap and are never truncated.

**Region budget.** Fixed bottom chrome (time bar + tab bar) takes at most 40 % of the viewport height; past it the time bar collapses to its one-line running summary, and at 200 % zoom it scrolls with content.

**Hit targets.** 48 × 48 dp on Android, 44 × 44 px on the web, reached with `hitSlop` when the visual is smaller; adjacent targets ≥ 8 apart.

### Named Rules
**The One Surface Rule.** A screen is one ground with grouped lists on it. No cards in cards, no hairline around every container, no bordered boxes stacked in a column.

**The Notebook Grid Rule.** The dot grid exists only behind Day's timeline. It never becomes a page background, a card texture or a decoration elsewhere.

## Elevation & Depth

Depth is a tonal step. Light goes white-on-paper (cell on app); dark goes lighter-on-darker. Shadows exist only in light and only for floating layers; in dark a floating layer is a lighter surface with a 1 px inner hairline and a deep, unblurred-looking drop. Content never floats.

### Shadow Vocabulary
- **Overlay, light** (`box-shadow: 0 12px 32px rgba(20, 28, 70, 0.14), 0 2px 6px rgba(20, 28, 70, 0.06)`): sheets, dialogs, popovers, toasts, tooltips.
- **Overlay, dark** (`box-shadow: 0 0 0 1px rgba(190, 200, 255, 0.08), 0 16px 40px rgba(0, 0, 0, 0.5)`): the same layers in dark.
- **Card, light** (`box-shadow: 0 1px 2px rgba(20, 28, 70, 0.05)`): only the desktop running card. None in dark.

### Named Rules
**The Float-Only Rule.** Elevation is for things that float (sheets, dialogs, popovers, toasts, tooltips). Lists, rows, groups and notices sit flat on their ground.

**The One Boundary Rule.** A hairline and a fill never both mark the same boundary. No border around cells, cards, chips at rest, tags or the composer; a 1 px `outline` appears only on a control with no fill to mark it.

## Shapes

Soft, consistent corners that nest: `xs` 4 (chart chips, the selected-row bar, the Stop glyph), `sm` 8 (small buttons, the segmented thumb's inner shapes, fields inside cells, project tags, nav items, tooltips), `md` 12 (buttons, fields, the composer, time-bar buttons), `lg` 16 (grouped-list groups, the running card, popovers, toasts), `xl` 20 (desktop dialogs), `sheet` 28 (phone sheet top corners), `pill` (chips, switches, badges, the segmented track, the tab indicator, progress tracks, round icon-button state layers).

Lines are part of the form language: 1.75 px icon strokes, 1 px category lines, the 1 px dashed draft border, the 3 px leading selection bar, the red now-line.

### Named Rules
**The Nested Radius Rule.** Inner radius = outer radius − padding, never below `xs`: a 16-radius group with 8 inset holds 8-radius controls.

**The Rare Pill Rule.** Pills are for chips, switches, badges, the segmented track and indicators. Tags are not pills in this world; they are `sm` rectangles, like a label written on the page.

## Components

Every component is built on one set of kit primitives (`Pressable`, `Text`, `Icon`, `Surface`/`Group`/`List`, `ListRow`, `SectionHeader`, `ScreenHeader`, `Disclosure`, `Presence`, `Sheet`, `Dialog`, `Popover`, `Toast`, `TextField`, `Link`/`NavItem`); screens never use a raw `Pressable`, `Text` or `TextInput`. Icons are lucide, stroke 1.75 at every size (16 inline, 20 control, 24 bar), `label-secondary` by default, `label-primary` when the icon is the only label, ink only when it is the primary action; no text glyphs as icons. Haptics on Android only: check-off Confirm, start/stop/switch Clock_Tick, menu long-press Long_Press, refusal Reject.

**State layer (every pressable).** Rest · hover `fill-1` (only with a hover pointer) · pressed: Android ripple `fill-3` (borderless on icon buttons), web `fill-2` overlay in 0 ms, out in 100 ms · focus-visible ink ring 2 px + 2 px offset following the shape · selected: role-specific, never colour alone · disabled: labels `label-quaternary`, fills `fill-1`, never opacity. Forced colours map selected to `Highlight`, the ring to `Highlight`, boundaries to `ButtonBorder`.

### Buttons
- **Shape:** gently rounded (`md`, 12) at 48 (`lg`) and 44 (`md`) heights; `sm` is 32 visual with `sm` (8) corners and an extended target. Label `callout` 600, optional leading 20 icon and a trailing key hint (⌘/Ctrl, Alt+N style, only with a keyboard).
- **Primary:** ink fill, On-Ink label; pressed Ink Pressed. One per view.
- **Secondary:** tonal `fill-2`, Graphite label, no hairline.
- **Plain:** no fill, Ink Text label (Undo «Вернуть», Today, text actions).
- **Destructive:** Red Margin wash fill, Red Margin label; Wipe data and Delete account share size and width.
- **Hover / Focus:** state layer above; loading swaps the icon for a spinner and keeps the label (width never jumps). No scale on press.
- **Width:** content-width on medium/expanded; fill on compact for the screen's main action and inside sheets; equal halves for a split pair (Focus and Done). A split button adds a trailing chevron segment for other outcomes.

### Chips
- **Style:** neutral pill, `fill-2`, `label-secondary`, `subhead` label, 32 visual height, max width 180 (truncate). Project identity is an 8 px `stroke` dot before the name, never a filled chip. No coloured outlines.
- **State:** selected = Ink Wash fill + Ink Text label + a leading check (non-colour carrier). Filter chips are checkboxes; choice chips (≤ 4 options) are radios in a named group. Compact: one scrolling row; expanded: the strip wraps, past two rows a «Ещё N» chip opens a popover.

### Tags
- **Style:** a `sm` (8) rectangle, 20 high, 4 px side padding, `caption` label. Project tag = hue `tint` fill + hue `ink` text, no dot, no border. «В работе» uses the violet hue. Tags appear only in rows and cards; in a header, field or picker a project is a value (category-style mark + name), never a tag. Truncate at 50 % of the row's text width.

### Cards / Containers
- **Corner Style:** groups and the running card `lg` (16).
- **Background:** `bg-cell` on `bg-app`.
- **Shadow Strategy:** flat (see Elevation); only the desktop running card takes the card shadow.
- **Border:** none; rows inside a group are divided by `separator`, inset to the text start.
- **Internal Padding:** rows 16 × 12; the running card 12; notices use row padding on `bg-cell` with a status wash where they carry status.

### Inputs / Fields
- **Style:** 48 (Android) / 44 (web) high, `md` corners, 12 side padding, `body` text, `label-tertiary` placeholder; `bg-inset` inside a cell or `bg-cell` on the app ground, with a 1 px Ruled Edge border. A visible `footnote` label above (a real `<label for>` on the web).
- **Focus:** the ink ring 2 px + 2 px offset on focus by any input method; hover darkens the border to `label-tertiary`.
- **Error / Disabled:** error = Red Margin border + a `footnote` message with an alert icon, only after blur or a submit attempt; disabled = `fill-1`, `label-quaternary` text, no border. Multiline grows 3 → 8 lines, then scrolls.
- **Draft:** text the assistant is still reading shows as a draft line: 1 px **dashed** Ruled Edge border, `md` corners, `label-secondary` text, an inline spinner. The same device marks proposals (a 2 px dashed leading rule).

### Navigation
- **Phone (compact):** a Material navigation bar on `bg-cell`, 64 content height plus the inset, four equal destinations (Now · Day · Inbox · More). Selected: a 64 × 32 `fill-3` pill behind a filled icon, `label-primary` 600 label; unselected: outline icon and label in `label-secondary`. Hidden while the keyboard is up. On the web it is a `nav` of links.
- **Desktop (expanded):** a 248 sidebar on `bg-sidebar` with a `separator` edge: the Pace mark + «Pace» + the bell; the account row; «Новая задача» as the shell's one primary button; 44-high nav items (`sm`, 20 icon, `callout` label, trailing danger badge on Inbox). Current: `fill-3` + `label-primary` 600 + a 3 px leading ink bar (`xs`) + `aria-current="page"`.
- **Medium:** an 80-wide rail, icon over a `caption` label, same states.
- **Period control:** one `PeriodStepper` on Day, Week, History and Insights: a `fill-2` pill track (40 high) with ‹ range › and a «Сегодня» plain button shown only away from today, in a reserved slot.

### Check circle and task row
- **Check circle:** a 24 circle with a 1.75 Ruled Edge ring. It fills on pointer-down (ink disc + On-Ink check, 100 ms) and then the row fades out (160 ms), the rows below close up (220 ms) and an Undo toast appears; ≤ 300 ms in total, the same on Android and the web. Checked at rest (Done lists, History): a `label-secondary` disc, and the title in `label-secondary` with a strikethrough. Closed tasks are neutral, so a Done list is never a column of ink.
- **Task row:** check · title (`body` 500, clamp 2) · meta line (`footnote` `label-secondary`: project tag, importance word only when not Normal, repeat icon, due time); late times in Red Margin. Selected in the inspector: `selection` fill + 3 px leading ink bar.

### Time bar and running card (signature)
- **Time bar buttons:** four fixed tiles (Calendar, Task, Chores, Rest), equal width, ≥ 52 high, `md` corners, a 20 icon over a `caption` label. At rest: neutral `fill-2` tile, icon in its category `stroke`, label `label-secondary`. Running its activity: hue `tint` fill, hue `ink` label 600, and the state in the name. The tiles stay visible while something runs; only the typed field folds.
- **Running card:** `bg-cell`, `lg`, a category mark and the name (`body` 600) with Stop (a secondary button with a **filled** rounded-square glyph); the elapsed time in Numeric Live; «из ~20 мин» in `footnote`; then the running line, drawn as an ink line with a red mark at the expected length, turning Burnt Orange past it, with «Всё ещё занимаетесь?» and «Да, ещё». No pulsing dot: the live time is the motion. A one-line variant serves the folded bar, a parallel activity and the desktop shell indicator.

### Day timeline (signature)
- An editable list beside a proportional rail; the rail and blocks sit on the faint dot grid (4-pt spacing, `grid` colour) with a 1 px red now-line across the current minute. Category blocks carry their pen-colour line; gaps read «не записано» with one Log action.

### Overlays
- **Sheet (compact):** `bg-elevated`, `sheet` top corners, 20 padding, a real 48 dp drag zone with a 32 × 4 `label-quaternary` handle; title `title2`; sticky actions footer; slides from its own measured height and back down (280 / 200 ms), the scrim fades in place; detents medium/large; Back, swipe and (web) a close button dismiss.
- **Dialog (expanded):** centred, 560 (forms) or 400 (confirmations), `xl` corners, scale 0.96 → 1 + fade (never from 0).
- **Popover / Menu (expanded):** anchored to its trigger, 360 wide, `lg` corners, opens from the anchor's edge.
- **Toast:** `bg-elevated`, `lg`, `callout` message (clamp 2) with at most one plain action and a close button; anchored 8 above the measured bottom chrome or the cause's region, never in the sidebar, never over the next action; 8 px rise + fade in, fade + 4 px drop out.
- **Tooltip (web):** `bg-elevated`, `sm`, `footnote`, max 280, after 400 ms hover (0 on focus, 0 for a "why unavailable" hint), hoverable, Escape dismisses; never on tap.

### Motion
Durations 100 (press, hover) · 160 (fades, thumbs) · 220 (disclosure, toast, close-up) · 280 (sheet, dialog, route push), exits at 0.7 ×; ease-out `cubic-bezier(.2,.8,.2,1)` to enter, ease-in `cubic-bezier(.4,0,1,1)` to exit, `cubic-bezier(.3,0,0,1)` for in-place change. Keyboard navigation, list mounts, filter changes and day/week switches get no motion. Reduced motion replaces travel and scale with a 160 ms fade, never a blank hole. The next step waits for the animation's completion, never a timer.

## Do's and Don'ts

### Do:
- **Do** keep ink blue (#2E4AD6 / #97A9FF) as the only interactive colour, with at most one filled ink element per screen at rest.
- **Do** reserve Red Margin (#C3352B / #FF8274) for the now-line, overdue, Urgent, destructive and errors.
- **Do** show a category as a 1 px line or small dot in its hue `stroke` with the name in `label-*`, and a project as a `sm` tag in hue `tint` + `ink`.
- **Do** put every number through a numeric role (tabular figures) and the core formatter, with non-breaking spaces in Russian.
- **Do** build screens as one `bg-app` ground with `bg-cell` groups (`lg`, 16) and inset separators.
- **Do** give every pressable the one state layer: `fill-1` hover, ripple `fill-3` / `fill-2` overlay, a 2 px + 2 px ink focus ring, `label-quaternary` + `fill-1` when disabled.
- **Do** check every decision in both themes, in Russian, at 320 / 390 / 1440 and at font scale 1.6.
- **Do** pair every overlay's enter with its exit, stay under 300 ms, and give each a reduced-motion fade.

### Don't:
- **Don't** put an eyebrow, kicker or small label above a title.
- **Don't** use red as decoration, as a category colour or as a brand accent.
- **Don't** use the logo lime (#5E8C00 / #C8F03C) anywhere but the logo, favicon and app icon.
- **Don't** show "Normal" importance, or give importance its own colour beyond the red Urgent word.
- **Don't** nest cards in cards, outline every container, or mark one boundary with both a hairline and a fill.
- **Don't** put shadows on content; elevation belongs to sheets, dialogs, popovers, toasts and tooltips.
- **Don't** use text glyphs (↵, ⋯) as icons, an outlined square for Stop, or a pulsing running dot.
- **Don't** use pill tags or tags with dots; tags are `sm` rectangles.
- **Don't** spread the dot grid beyond Day's timeline.
- **Don't** use off-scale spacing, radii, font sizes or arbitrary values; the token scales are the only scales.
- **Don't** dim disabled controls with opacity, or show state by colour alone.
- **Don't** animate list mounts, filter changes or day switches, or pair a fixed timer with an animation.
