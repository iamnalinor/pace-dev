# Pace logo

`pace-mark.svg` is the mark from design board "08 · Step" (two chevrons and a dot) in the dark palette on a transparent background; `pace-mark-light.svg` is the mono variant for light surfaces; `pace-wordmark.svg` is the mark followed by the word "pace" (Geist 600, letter-spacing -0.04em, font not embedded); `favicon.svg` is the chevrons on a lime tile for browser tabs and home screens. All four files and every committed PNG icon (`apps/app/public/{favicon.svg,icon-192.png,icon-512.png,apple-touch-icon.png}`, `apps/app/assets/{icon,adaptive-icon,adaptive-icon-mono,splash-icon,notification-icon}.png`, `assets/logo/bot-avatar.png` — the Telegram bot's profile photo, the dark app icon sized to survive the circular crop, set once through the Bot API `setMyProfilePhoto`) are generated from `scripts/generate-icons.ts`: edit the mark there and run `bun scripts/generate-icons.ts` to regenerate everything (the output is deterministic, so unchanged assets produce no diff).
