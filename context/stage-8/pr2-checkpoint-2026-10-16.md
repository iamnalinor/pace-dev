## Что внесено в рабочую ветку

- Перевод `proposal` → `action` через core, API, client, приложение и бота:
  предварительный разбор, карточки Approve/Cancel, уточнение запроса, rule fallback,
  применение действий и Undo для обратимых операций.
- Серии регулярных задач и экземпляры, двухэтапные сроки, оценки задач,
  активностей и категорий; новые пользовательские данные проходят через события.
- Now: панель текущей активности, отдельные компактные группы задач со сроком
  и без срока, открытие созданной ассистентом задачи; Day: детали и редактирование
  активности, связь с одной задачей, использование приложений и экранное время.
- Формы, пресеты, настройки уведомлений, аватар Telegram через Pace, ссылки
  на задачи и маршруты уведомлений; подтверждение Wipe/Delete в Telegram.
- Последние исправления по отзыву владельца: полная ссылка на экране задачи;
  только существующие проекты для действий ассистента; сохранение полного
  введённого названия; закрытие календаря после выбора даты и клика снаружи;
  быстрое редактирование описания; сохранение ожидания входа через бота после
  перезагрузки страницы; классификация «ем» как Food в локальном коде.
- Настраиваемый OpenAI-совместимый endpoint (`LLM_BASE_URL`, `LLM_MODEL`, один или
  несколько ключей `LLM_API_KEY`) вместо жёстко выбранного провайдера. Без
  модели и при лимите запросов веб и бот показывают проверяемые EN/RU
  предложения по правилам. При полном отсутствии модели `defer` не создаёт
  бессрочную очередь. Оценка категории до выбора показывает `Default (1h)`
  только на выбранной плашке; после выбора ручного значения оно заменяет default.
