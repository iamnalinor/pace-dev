# Agent instructions

Fullstack template: Bun workspaces — `apps/api` (Elysia + better-auth + Drizzle/PostgreSQL),
`apps/web` (React + Vite + shadcn/ui, Eden client), `e2e/` (Playwright). Read
[docs/architecture.md](docs/architecture.md) before changing structure.

## Rules

- **Bun only**: `bun install`, `bun run <script>`, `bunx <tool>`. Never npm/npx/yarn/node.
- **After every change run `bun lint`** and fix everything it reports. Do not run
  biome/eslint/tsc/knip separately — `bun lint` is the single entry point (it auto-fixes).
- **Tests first (TDD)** for behaviour changes. Pick the level per [docs/testing.md](docs/testing.md):
  unit tests only for non-trivial logic; API behaviour → integration tests through Eden;
  user journeys → Playwright. Run `bun test:unit`, `bun test:integration` (needs Docker, or
  `TEST_DATABASE_URL`), `bun test:e2e` (needs `docker compose up -d db`).
- **Never** disable a lint rule inline without `-- <reason>`; never weaken a rule to pass
  lint — fix the code. Never skip or delete a failing test.
- **Architecture** (enforced by dependency-cruiser): inside an API feature
  `domain ← application ← {infrastructure, http}`; domain/application are pure and
  immutable; features never import each other; the web app imports the API with
  `import type` only.
- **Errors**: use cases return `Result<T, E>` with string-literal error codes; the HTTP layer
  maps them with an exhaustive `switch` (no `default`).
- **Elysia routes**: keep chains unbroken (Eden infers from them); route options are
  factories (`() => ({...})`), never shared constants — Elysia mutates them.
- **Database**: change `*-table.ts`, then `bun db:generate --name=<what>`; review and commit
  the SQL. Never edit an applied migration, `apps/api/drizzle/meta/*` or
  `apps/api/src/auth/auth-schema.ts` (generated by the better-auth CLI) by hand.
- **Web imports** use the `#web/*` alias; API code uses relative imports.
- **UI components**: `bunx shadcn@latest add <name>` inside `apps/web`, then run
  `bun lint`. Check that generated imports point to `#web/shared/lib/cn.ts` (the CLI may
  add a bogus `cn` npm package — remove it).
- Code, comments and identifiers in English. Everything that exists only as an example
  is named `example*` / `Example*`.
